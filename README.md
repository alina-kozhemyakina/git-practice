# Git и Git Bash — практическая работа

## О проекте

Учебный проект, созданный для освоения системы контроля версий Git и практики работы с репозиториями через Git Bash.

В рамках практики выполняла основные операции с файлами, коммитами и ветками, изучала процесс объединения изменений и разрешения конфликтов слияния.

## Используемые инструменты

- Git
- Git Bash
- GitHub

## Выполненные задачи

### 1. Работа с репозиторием
- Инициализировала локальный Git-репозиторий.
- Клонировала существующий репозиторий.
- Проверяла состояние рабочего каталога.

### 2. Работа с файлами
- Создавала файлы и папки.
- Добавляла новые файлы в индекс Git.
- Сохраняла изменения с помощью коммитов.

### 3. Работа с ветками
- Создавала новые ветки.
- Переключалась между ветками.
- Объединяла изменения из разных веток.

### 4. Разрешение конфликтов
- Практиковалась в создании конфликтов слияния.
- Анализировала конфликтующие изменения.
- Разрешала конфликты и завершала слияние веток.

### 5. Синхронизация с GitHub
- Отправляла локальные изменения в удалённый репозиторий.
- Получала изменения из удалённого репозитория.

## Использованные команды Git

| Команда | Назначение |
|---|---|
| `git init` | Создание локального репозитория |
| `git clone` | Клонирование репозитория |
| `git status` | Проверка состояния репозитория |
| `git add` | Добавление изменений в индекс |
| `git commit` | Сохранение изменений |
| `git branch` | Просмотр и создание веток |
| `git checkout` | Переключение между ветками |
| `git merge` | Объединение веток |
| `git push` | Отправка изменений на GitHub |
| `git pull` | Получение изменений из удалённого репозитория |

## Полученные навыки

- Работа с локальными и удалёнными репозиториями.
- Управление версиями файлов.
- Создание и переключение между ветками.
- Объединение изменений.
- Разрешение конфликтов слияния.
- Синхронизация локального репозитория с GitHub.
